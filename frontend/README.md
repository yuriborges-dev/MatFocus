# Frontend — MatFocus

Este diretório contém a interface web do MatFocus, desenvolvida com React, TypeScript, Vite e Tailwind CSS.

## Responsabilidades

- Interface do usuário
- Telas de autenticação
- Dashboard do aluno
- Fluxo de atividades matemáticas
- Mapa de fases
- Página de progresso
- Página de conquistas
- Perfil e configurações do usuário
- Consumo da API REST do backend

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React

## Execução local

```bash
npm install
npm run dev
```
