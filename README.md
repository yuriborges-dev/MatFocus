# MatFocus

Sistema web educacional gamificado para apoio ao ensino de matemática para crianças com TDAH.

## Tecnologias

Frontend:
- React

Backend:
- Django
- Django REST Framework

Banco de dados:
- PostgreSQL

Infraestrutura:
- Docker

## Estrutura

frontend → interface do usuário  
backend → API REST  
docs → documentação técnica do projeto
